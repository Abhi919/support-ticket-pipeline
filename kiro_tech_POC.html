KIRO MULTI-AGENT SPEC DRIVEN SDLC PIPELINE – IMPLEMENTATION PLAN
Goal: Build an autonomous 5-Agent SDLC pipeline in Kiro where every Jira ticket goes through understanding, development, testing, review and security audit.

FOUNDATION &
GOVERNANCE SETUP

  • Create .kiro/ structure (agents, prompts, steering, hooks)
  • Write global governance AGENTS.md
  • Create shared steering files (product, coding standards, security, testing, etc.)
  • Create Skills Library for Agent2 (implementation skills)
  • Define workflow principles and artifact contract
Deliverable

Governance layer, steering and skills library ready

CUSTOM AGENT
CREATION

  • Create 5 agent definition files (JSON) in .kiro/agents/
  • Attach prompts and resources (AGENTS.md, steering/**, specs/**)
  • Create role prompt files for all agents in .kiro/prompts/
  • Map skills/** only for Agent2 (development agent)
  • Validate agents in Kiro
Deliverable

All 5 agents registered with prompts and resources

MASTER BOOTSTRAP
ORCHESTRATOR

  • Implement /spec <Jira-ID> command
  • Validate Jira ticket via MCP
  • Create /specs/<ticket-id>/ folder with standard artifacts
  • Pre-create all artifact files
  • Create spec-manifest.json (metadata)
  • Trigger Agent1 automatically
Deliverable

One-command spec bootstrap and Agent1 trigger ready

HOOK AUTOMATION
PIPELINE

  • Create hooks file spec-driven-pipeline.yml
  • Define file based triggers for agent handoff
  • Hook1: spec_created → A1
  • Hook2: requirements.md → A2
  • Hook3: implementation-notes.md → A3
  • Hook4: test-cases.md → A4
  • Hook5: review-report.md → A5
  • Test first 2 hooks end-to-end
Deliverable

Automatic agent chaining (Hook based) functional

AGENT2 SKILLS ENGINE
& INTELLIGENCE

  • Build dynamic skills resolver logic for Agent2
  • Map requirement keywords to relevant skills files
  • Agent2 auto-loads required skills (mongo, caching, exception handling, etc.)
  • Enhance Agent2 prompt for context-aware development
  • Test skill selection on sample requirements
Deliverable

Agent2 uses relevant skills dynamically based on need

END-TO-END TESTING
WITH REAL TICKET

  • Run full pipeline on real Jira ticket
  • Validate outputs of all 5 agents
  • Check artifact quality at each stage
  • Fix prompt gaps, hook issues, formatting issues
  • Collect feedback and improve
Deliverable

Full pipeline tested with real Jira ticket

STABILIZATION &
DEMO PREPARATION

  • Refine prompts and outputs
  • Add human approval checkpoints
  • Generate final-summary.md
  • Prepare documentation (usage guide, process flow, limitations, future scope)
  • Internal demo to senior stakeholders
Deliverable

MVP ready for demo and internal adoption
